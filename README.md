## 🛠️ What I've Built in LessonFlow

- **Timetable:** drag-and-drop builder, versions, co-teachers, substitutions and supervision
- **Academics:** lesson plans with HOD approval, AI worksheet and question-paper generation, notebook checking and observation reports
